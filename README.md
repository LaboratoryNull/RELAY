# Relay — SSH Manager

Desktop-приложение на Wails + React с настоящим PTY-терминалом, автоматически
пополняемой историей SSH-хостов и контекстной SFTP-панелью.

## Возможности

- системная login shell внутри xterm.js с поддержкой ANSI, resize и scrollback;
- обычные команды OpenSSH, например `ssh root@19.4.2.1`;
- сохранение SSH-цели только после успешной авторизации;
- безопасное хранение введённого пароля в системном хранилище секретов;
- поиск, избранное и быстрый повторный вход без повторного ввода пароля;
- несколько независимых PTY-вкладок; клик по хосту открывает новую вкладку;
- SFTP-раздел появляется автоматически после успешного SSH-входа;
- навигация по удалённым каталогам и контекстное меню файлов;
- рекурсивное копирование, перемещение, удаление, скачивание и загрузка директорий;
- загрузка локальных файлов и папок перетаскиванием или вставкой из буфера;
- метаданные истории хранятся с правами `0600` в пользовательском config-каталоге.

Пароли не записываются в `hosts.json` и не передаются обратно в JavaScript. Для
них используется Secret Service в Linux, Keychain в macOS или Credential Manager
в Windows.

SFTP-проводник использует постоянное соединение, открытое после подтверждённой
SSH-аутентификации. Поддерживаются сохранённый пароль, `ssh-agent` и стандартные
незашифрованные ключи из `~/.ssh`.

## Запуск

```bash
wails dev
```

## Сборка

```bash
wails build
```

В конфигурации включён build tag `webkit2_41`, соответствующий WebKitGTK 4.1.
Готовый Linux-бинарник будет находиться в `build/bin/ssh-manager-ui`.

go test ./...
